# Legacy Navigator

Build me a minimal, clean personal e-portfolio website for a software developer. Design language: lots of white space, subtle grays, one accent color (pick a calm, confident color like deep teal or muted blue), clean sans-serif typography (e.g. Inter or similar), understated micro-interactions on scroll/hover — nothing flashy or gimmicky. Should feel professional enough for job hunting and freelance client outreach, but personal and human, not corporate-template generic.

Sections needed:

Hero / About Me

Name, title (Software Developer — PHP/CodeIgniter specialist), short intro

A tagline that signals I solve real, messy legacy-system problems, not just build shiny new apps

Brief personal intro: I work primarily in PHP (CodeIgniter 1 & 4, Doctrine ORM, MySQL/MariaDB), specializing in enterprise systems like HR platforms, sales ERPs, and system integrations

Projects / Case Studies — build these as 3 expandable case-study cards, each with: the problem, what I did, the outcome/impact

IMS System Enhancements: Ongoing management and feature development of an internal IMS system, directly implementing and enhancing features based on live client requests — emphasize responsiveness to real business needs

IRAS APEX API Integration: Migrated the HR system's statutory reporting from a legacy API to IRAS's new APEX API — emphasize the complexity of working with government/statutory integrations and getting it right (compliance-critical, zero room for error)

CI1 → CI4 Migration (in progress): Leading the migration of a legacy CodeIgniter 1 HR platform (Leaves, Payroll, CPF, Attendance modules) to CodeIgniter 4 — emphasize the engineering discipline required: treating legacy business logic as source of truth, parallel-run verification for high-risk statutory modules, and maintaining a live system while rebuilding its foundation

"Behind the Code" — a personal, non-copyable section

A short, personality-driven segment (not a generic "fun facts" list) built around: how I actually debug — the unglamorous, methodical reality of tracing a bug through legacy code, hunting down a root cause (e.g. an orphaned database row silently breaking notifications), and the satisfaction of finding it

Include one specific, real anecdote or two written in first person, conversational tone — something only I could have written, not AI-boilerplate

Optionally a small "currently exploring" note about a side interest (e.g. an offbeat passion project) to add texture — keep it light, one line

Skills / Tech Stack — visually simple, grouped by category (Backend, Database, Frontend/Tooling, Integrations) rather than a generic tag cloud

Contact — simple form + direct email/LinkedIn links, minimal friction

Keep copy confident but not boastful, concrete over buzzwordy. Avoid stock photos — use clean geometric/abstract visuals or code-snippet aesthetics instead. Fully responsive.
